# shell00 — Introduction to the Shell

Welcome to your first Cyber Alliance UIC module. This repository is your
student workspace for the Shell00 assignment and is graded automatically every
time you push.

## What you will build

This module contains three exercises:

- [starter/ex00](starter/ex00) — `whoareyou`
- [starter/ex01](starter/ex01) — `count_args`
- [starter/ex02](starter/ex02) — `safe_div`

## Student workflow

1. Read [subject.md](subject.md) carefully.
2. Implement each solution inside the matching folder under [starter](starter).
3. Make your scripts executable.
4. Commit and push your work.
5. Open the GitHub Actions tab to see your grading result.

## Run the grader locally

Use the same grader that GitHub Actions runs:

```bash
chmod +x grader/run.sh
./grader/run.sh
```

You will receive instant PASS/FAIL feedback for each exercise.

## Important rules

- Only edit files inside [starter](starter).
- Keep each script executable and start with `#!/bin/sh`.
- Respect the behavior described in [subject.md](subject.md).
- Do not modify the grader infrastructure unless instructed by a mentor.

## Getting help

If you get stuck, ask a mentor for help. Do not share full solutions publicly.
