# Student Guide

## Workflow

1. Accept the GitHub Classroom assignment.
2. Clone your repository.
3. Open the exercise folder for the task.
4. Implement the corresponding shell script.
5. Make the script executable.
6. Commit and push your changes.
7. Watch the GitHub Actions workflow grade your submission.

## Expectations

- Keep each exercise isolated.
- Prefer simple, readable Bash.
- Do not use forbidden commands.
- Read the subject PDF for the official rules.
